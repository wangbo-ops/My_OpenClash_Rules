# My OpenClash Rules

个人自用的 OpenClash 订阅转换模板，仅按自己的需求维护，不提供对外使用支持。仓库保持公开是为了方便自己的订阅转换服务读取。

个人模板地址：

```text
https://raw.githubusercontent.com/wangbo-ops/My_OpenClash_Rules/main/cfg/Custom_Clash.ini
```

- 每天北京时间 **05:30** 检查上游并更新，通过校验后发布。
- 个人设置：[custom/settings.json](custom/settings.json)。
- 运行记录：[Actions](https://github.com/wangbo-ops/My_OpenClash_Rules/actions)。
